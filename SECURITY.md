# CrimeMaps security policy / Sicherheit / 安全

## Security

The website and related services can still be attacked or become unavailable. Existing safeguards cannot remove every risk.

For a security issue, open this repository’s Security → Advisories page. If “Report a vulnerability” is available, use that private form. If it is absent, private reporting is not enabled. Do not put passwords, access keys, private feedback or identifying case details in a public issue. You may open a public issue asking for a private reporting channel without disclosing the vulnerability.

Include the affected city and page, the software version if known, what you expected to happen, and a small example that reproduces the problem. Test only systems you own or are authorized to test. Avoid automated traffic, accessing other visitors’ feedback or changing public counts. This project offers no payment for vulnerability reports or guaranteed response time.

Support covers the current software and versions being prepared for updates. Old maps preserve historical sources; they do not mean that old software will continue to receive updates. When suggesting a correction, retain the source’s uncertainty about what happened and where.

Optional visit statistics and private feedback are not connected to a live service and are currently disabled. For these features, CrimeMaps does not save your IP address. Service providers still receive connection information. If enabled, these features briefly keep a code derived from the connection address to limit abuse; this is not fully anonymous. Feedback is intended for authorized project operators, but the service provider also processes it. Never send sensitive personal details, passwords or access keys.

## Sicherheit

Die Website und die zugehörigen Dienste können weiterhin angegriffen werden oder ausfallen. Die vorhandenen Schutzmaßnahmen können nicht jedes Risiko beseitigen.

Öffnen Sie bei einem Sicherheitsproblem in diesem GitHub-Projekt unter Security → Advisories. Wenn „Report a vulnerability“ angezeigt wird, können Sie das private Formular verwenden. Fehlt die Schaltfläche, ist die private Meldung nicht aktiviert. Veröffentlichen Sie keine Zugangsdaten, privaten Rückmeldungen oder Angaben, die Personen in einem Fall identifizieren. Ein öffentliches Issue darf um einen privaten Meldeweg bitten, ohne die Schwachstelle offenzulegen.

Nennen Sie die betroffene Stadt, Seite oder Softwareversion, das erwartete Verhalten und ein kleines nachvollziehbares Beispiel. Testen Sie nur Systeme, die Ihnen gehören oder für deren Prüfung Sie eine Erlaubnis haben. Vermeiden Sie automatisierte Anfragen, den Zugriff auf fremde Rückmeldungen und Änderungen öffentlicher Zähler. Das Projekt bietet keine Bug-Bounty-Vergütung und keine garantierte Antwortfrist.

Gepflegt werden die aktuelle Software und Versionen, die für Aktualisierungen vorbereitet werden. Alte Kartenstände dokumentieren historische Quellen; sie bedeuten nicht, dass alte Software weiterhin aktualisiert wird. Unsicherheiten von Quellen und Ortsangaben müssen auch bei Korrekturmeldungen erhalten bleiben.

Die optionalen Besuchsstatistiken und privaten Rückmeldungen sind noch nicht mit einem produktiven Dienst verbunden und bleiben derzeit deaktiviert. Die Anwendung speichert für diese Funktionen keine ursprünglichen IP-Adressen; Dienstleister verarbeiten weiterhin Netzwerkanfragen. Zum Schutz vor Missbrauch wird vorübergehend ein aus der Verbindungsadresse abgeleiteter Kennwert verwendet. Auch ein solcher Kennwert kann Anfragen miteinander verbinden; er macht sie nicht vollständig anonym. Rückmeldungen sind nur für befugte Betreiber sichtbar, gegenüber dem Dienstleister aber nicht anonym. Senden Sie keine sensiblen personenbezogenen Angaben oder Zugangsdaten.

## 安全问题反馈

网站和相关服务仍可能遭到攻击或出现故障，现有保护不能保证消除所有问题。

发现安全问题时，请打开本仓库的 Security → Advisories。若页面显示“Report a vulnerability”，可通过该私密表单报告；没有此按钮则表示私密报告尚未启用。不要在公开 Issue 中填写凭据、私密反馈或能够识别公告当事人的信息。可以开一个不含漏洞细节的 Issue，请维护者提供私密渠道。

报告请说明受影响的城市、页面或仓库版本、预期行为，以及发生问题时的具体操作。只测试自己拥有或获准测试的系统。不要发送自动化流量、读取他人的反馈或修改公开计数。本项目没有漏洞赏金，也不承诺固定回复期限。

维护范围是当前部署的软件和准备更新的版本。旧地图保留历史来源，不代表旧软件会继续获得更新。反馈内容问题时，请保留来源链接与已知的地点不确定性。

访问统计和私密反馈尚未正式接入，目前保持关闭。接入方案中，应用不保存原始IP地址，服务商仍会处理网络连接；应用会短期保存根据连接地址生成的临时编号，用于限制重复请求，这不能保证完全匿名。反馈仅向获授权的网站运营者开放，不代表对服务商匿名。请勿提交敏感个人信息或凭据。
