# Announcement statistics method v1

The software describes the included public reports. It does not estimate city safety, crime rates, unique crimes, or hate-crime prevalence. Sources are selected, collection can be incomplete, and no population/exposure denominator or comparable sampling probability is available.

The normal unit is one city/publisher-namespace/native-source-ID announcement. Its URL and source revision bind a current version, rather than creating new announcements. Identical repeated loaded rows are counted once. Conflicting rows, aliases with conflicting IDs, or stale input bindings fail. Follow-up reports remain separate announcements; unproven case identity is not merged. Munich retains its explicitly accepted POLIZEIKARTE entry unit and upstream occurrence-month basis. Those records cannot be pooled with the other cities' publication-month announcement counts for rankings.

A primary category belongs to an announcement once. Its fraction uses all unique included rows under the declared month/category filters, including unclassified and unknown-location records. Tags are multi-label; their fractions need not sum to 100%. The numerator is the number of included reports with that documented, source-backed reviewed tag. The denominator is all included unique reports. A separately returned fraction for completely assessed tags is available only when current explicit assessment-completeness evidence is provided. Empty tag lists never establish completed negative assessment. If no labels are documented and completeness is unknown, the public component suppresses a misleading table of zeros.

A possible hate-motive lead requires the accepted review's explicit police-suspected motive or reported bias-language/behaviour basis. It is not a police finding, and identity/nationality/religion/neighbourhood cannot supply the motive. The statistics module validates the tag envelope; original quote, current body/review hash and semantic verification remain the source-review pipeline's responsibility.

Map counting references are supplied by the existing checked map counting rule for the same included rows. The statistics module does not manufacture points, reinterpret roles, geocode or sum scene counts. A road/area/park/operation/discovery reference and an absent counting point do not imply zero crime. POI background totals or nearby associations are not exposure or risk denominators.

`summary_event_date_missing` measures only missing top-level summary `event_date` values. Dates in individual scenes or the original source may still be known. It is not an estimate of unknown original event dates. Collection time is recorded separately. Missing-period inventories are explicit when available; an empty inventory means coverage gaps have not been enumerated, not that collection is complete. Selection bias and missingness are described without a population confidence interval or fabricated numeric confidence.

`web/src/safety/indices.ts` performs pure statistics. `web/src/safety/methods.ts` mounts a native accessible `<details>` panel using text nodes. It has no network request or model call. Language and category/tag labels come from the shared language resources. Internal hashes, review notes, enums and acceptance state are not rendered to visitors.

`build_method_metadata.py` writes an ignored runtime sidecar using the accepted current manifest, monthly file hashes and existing required-check evidence. The input descriptor is supplied by the migration/city owner from their accepted checks. This helper verifies identity/file bindings; it does not perform source review or approve/publish a map. `docs/method-source-bases.json` records the normal and Munich source/time/unit contracts without live city data.

`evaluate_labels.py` is an offline scorer for supplied predictions and current reviewed labels. It reports missing predictions, per-label TP/FP/FN and precision/recall with explicit denominators. Incomplete gold tag assessment is excluded from negative-label comparison. It performs no inference and changes no decision. Small selected reviewed-label agreement is not independent population accuracy; source-quote checking remains separate. No new remote inference service is enabled by this change.
