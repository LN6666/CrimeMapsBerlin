# Feedback and discussion · Rückmeldungen · 反馈与讨论

Feedback and comments take place on the corresponding city’s GitHub project. Use **Discuss this map** to share your experience and suggestions, and **Report a problem** for errors or corrections with a link to a public source. Sign in to GitHub to post; your account and message are public. Do not include personal or sensitive information. This is not an emergency or police reporting service.

Rückmeldungen und Kommentare stehen im GitHub-Projekt der jeweiligen Stadt. Unter **Über die Karte sprechen** kannst du Erfahrungen und Vorschläge teilen. Unter **Problem melden** kannst du Fehler oder Korrekturen mit einer öffentlich zugänglichen Quelle melden. Für einen Beitrag musst du dich bei GitHub anmelden. Dein Konto und dein Text sind öffentlich. Bitte keine persönlichen oder sensiblen Angaben veröffentlichen. Dies ist kein Notruf und keine polizeiliche Meldestelle.

反馈和评论直接在对应城市的 GitHub 项目进行。**留言讨论**用于分享使用感受和建议，**报告问题**用于反馈错误；纠错时请附上公开来源。留言需要登录 GitHub，账号和内容都会公开。请勿发布个人信息或敏感资料。这里不接收报警或紧急求助。

The homepage’s GitHub icon opens the Berlin project. Each city page’s icon opens that city’s project. / Das GitHub-Symbol der Startseite öffnet das Berliner Projekt, das Symbol einer Stadtseite deren eigenes Projekt. / 首页底部图标通往柏林项目；各城市页面的图标通往该城市的项目。
