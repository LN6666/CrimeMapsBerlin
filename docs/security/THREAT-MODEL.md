# CrimeMaps security model

Reviewed on 2026-10-03. This is an implementation candidate. Integration, repository settings and real service configuration are separate acceptance steps.

The product consists of 14 independent static maps, reviewed public map JSON and assets, GitHub source/CI/Pages, optional GoatCounter country aggregates and direct public GitHub feedback. Official reports, OSM data, upstream classification, translated strings and visitor input cross trust boundaries. Source truth still depends on current source/semantic/geometry review; this security gate does not perform that review.

| Boundary / threat | Current evidence and candidate control | Remaining exposure |
|---|---|---|
| Report, POI, translated text → DOM / XSS | Current cards use textContent and DOM nodes. Keep that API for announcements/feedback; HTML template is only trusted static application text. security.ts rejects active schemes, controls, userinfo and nonstandard ports. CSP permits local executable assets; the optional GoatCounter flag adds only gc.zgo.at and the selected exact /count path. Cloudflare challenge and external-frame permissions are removed. | Translation files are executable-build input and need normal code review. CSP does not validate source facts or prevent an authorized compromised build. MapLibre needs inline CSS; no inline script or unsafe-eval is allowed. |
| Manifest → URL / traversal, exfiltration and browser exhaustion | Validate generation, YYYY-MM months, category/tile components, finite positive tile sizes and index counts. DataClient limits requests to its current local generation, rejects redirects, omits credentials/referrers; actual stream limit 64 MiB and cancellation remain. Cache weight is serialized UTF-16, not total heap. | A trusted but very large GeoJSON can still consume browser heap; performance limits and 14 integrated-browser checks remain required. |
| Static artifact → public site / unintended disclosure or mutation | artifact_gate.py rejects symlinks, runtime/review/SQLite/ZIP/PBF/source-map/credential signatures/private body fields, active SVG, unsafe HTML and multiple generations; 900,000,000 byte budget. Detached receipt binds commit, city and the exact file set/hashes. Verify against a separately trusted receipt SHA immediately before upload. | The scanner is a bounded allowlist and known-signature check, not a proof that arbitrary text contains no personal information/secrets. Semantic/redaction review remains mandatory. No runtime ZIP upload/extraction is exposed. |
| Source-review ZIP → offline local tools | Existing source_review_pack.py rejects traversal, duplicate members, symlinks and unchecked bytes; the website gate disallows ZIP entirely. | Offline review packs are private and do not belong in repository or Pages artifact. Hashes detect byte mismatch, not a malicious source. |
| Optional CSV/SVG export → spreadsheets/browser | No public CSV importer/exporter exists in the current map. Analytics SVG uses fixed elements, finite integers, escaped text and no remote references; gate validates SVG. If CSV is later added, neutralize leading =,+,-,@ and control prefixes before spreadsheet use. | JSON/CSV conversion outside the product can introduce formulas. A safe SVG rendering is not an authenticated statistic. |
| PR/dependency → CI secrets / supply chain | Existing workflow uses full commit SHA, contents:read, npm ci and uv --locked. Candidate disables checkout credential persistence, bounds job duration and supplies Dependabot/CODEOWNERS entries. Current npm audit reports 0 known advisories; current 132 tracked small files show 0 known credential signatures. | These scoped checks do not prove absence of vulnerabilities, stale transitive advisories or historical credential exposure. No self-hosted public PR runners; no pull_request_target/workflow_run executing untrusted PR artifacts with deploy secrets. |
| CI → release integrity / rollback | Build and test are read-only. Only a reviewed main commit receives a protected deployment job with pages:write and id-token:write. Keep source and artifact approval records outside public payload; verify trusted receipt digest. Retain an immutable last-good artifact and its receipt for rollback. | SHA-256 is not a deployed digital signature. No signing key/attestation trust root or anti-tamper service has been deployed here. A compromised account can replace a site. Protect owner account and repository settings; restore from independently retained accepted artifact. |
| Browser → counting / forged events and service availability | Cloudflare collection and backend are cancelled. The selected GoatCounter adapter must use fixed portal/city paths and titles, blank referrers, no automatic click tracking and no query/report/location/feedback data. Only public aggregate data can reach the map/ranking renderer. | Counts depend on provider filtering, blocking and session settings. Default deduplicated visits are not every page load. No live collector or aggregate acceptance is established by the cancellation patch. |
| Browser → feedback / public disclosure, identity and abuse | Visitors follow the correct city repository Issues/Discussions links and submit there themselves. The map has no private intake, email collection, deletion-code flow, operator API or Turnstile dependency. Explain that a GitHub account is required and the account/text are public; do not request personal information. | GitHub controls account access, public posts and moderation. Public comments are not anonymous or private. GitHub private vulnerability reporting remains a separate security channel. |
| Service → diagnostics / secrets and personal data | Keep GoatCounter API credentials only in ignored local configuration or GitHub Secrets; no VITE/browser/public-artifact token. Map requests omit credentials and use bounded caches. Global strict-origin-when-cross-origin preserves the origin for OSM tile policy; outbound report/GitHub links retain noreferrer. | GitHub, map providers and an enabled statistics provider process ordinary connection data. No claim of completely anonymous or IP-free transport. GoatCounter aggregate export must not expose individual visits or the full dashboard. |

## Privacy decisions for Germany/EU access

The owner cancelled Cloudflare feedback and statistics on 2026-10-03 and selected GoatCounter. The supplied account endpoint is `https://ryoushunnei.goatcounter.com/count`; account existence is distinct from acceptance of its actual settings and collection. The private Worker/D1/Turnstile architecture is retained only in Git/history and immutable prior deliveries, not as a current launch dependency.

GoatCounter's [privacy policy](https://www.goatcounter.com/help/privacy) describes aggregate storage and country derivation from connection IP. When sessions are enabled, its site/IP/User-Agent deduplication mapping can remain in memory for up to eight hours; full IP and User-Agent are not stored in the statistics database. The owner's accepted ryoushunnei account settings have Sessions=false and individual-pageview details disabled, so the configured metric is page views, not unique visitors or eight-hour deduplicated visits. This does not mean that no IP is processed or certify legal compliance. The actual operator/privacy notice must accurately describe the enabled service and settings before collection.

The actual [session/visit setting](https://www.goatcounter.com/help/sessions), rather than the provider default, determines the metric. With this account Sessions=false, reloads can increment page views; any explicitly excluded language-navigation reload must be described by the accepted adapter. Fixed paths/titles and blank referrers avoid sending map search, announcement IDs, coordinates or messages. Public data must remain country totals and overall totals, with source, metric and update time. No data means an unavailable state, not generated sample counts. The [CSP guidance](https://www.goatcounter.com/help/csp) supplies the script/count origins; this project narrows them to gc.zgo.at and its one selected account instead of a wildcard.

## Static hosting and limits

GitHub Pages is a static host; this candidate does not claim a configurable full WAF or prevention of denial of service. The [OSMF tile](https://operations.osmfoundation.org/policies/tiles/) and [vector](https://operations.osmfoundation.org/policies/vector/) policies require identifiable browser requests and bounded viewport usage; do not strip the tile Referer, bulk-download or bypass their caches.

Meta CSP can restrict resource loading but cannot set frame-ancestors, HSTS, Permissions-Policy or X-Content-Type-Options HTTP headers. If a reviewed reverse proxy/header-capable host is later configured, add those response headers there. Never describe a copied _headers file as effective on GitHub Pages. See [MDN CSP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP) and [frame-ancestors limitations](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/frame-ancestors).

The 900 MB artifact cap leaves room below the project's conservative 1,000,000,000-byte Pages budget. GitHub also applies soft bandwidth/build and rate limits: [Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits). No paid upgrade, replacement provider or additional automation is authorized. Cloudflare quotas, database/challenge credentials and cleanup tests no longer gate this product.

## Repository settings and incident handling

Migration is the only GitHub/settings/integration writer. For each of 14 repositories it must preserve existing history/protection and record default read token permission, no automatic PR approval, full-SHA Actions references, required current checks/reviews, no force push/deletion, private reporting and secret/push-protection state. Current read-only evidence is captured in the security stage; it is a point-in-time snapshot, not a promise about future settings. Private reporting must be enabled and independently read back before advertising a functioning private vulnerability endpoint. [GitHub secure-use guidance](https://docs.github.com/en/actions/reference/security/secure-use) and [private reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).

On a leaked credential, revoke/rotate it first; remove sensitive logs and assess access. Deleting the visible file or masking new logs does not revoke a key. Stop optional counting on suspected exposure; preserve a private incident record and redeploy only accepted bytes. On corrupted data/build failure, retain or restore last-good accepted artifacts; do not silently rebuild from unreviewed sources. Notify affected parties only through the owner-authorized incident process, with statutory breach obligations evaluated for the actual incident. No external notifications were sent by this audit.

## Required integration evidence

- security.ts is wired into all manifest/data requests; month/viewport cancellation and caches pass after the three-way merge.
- Built HTML has restrictive CSP before executable elements. Cloudflare challenge/frame permissions and old API/Turnstile flags are removed. GoatCounter permissions are opt-in and restricted to gc.zgo.at and the selected count account.
- artifact seal/verify pass for each single-city accepted artifact, trusted receipt SHA is outside payload, and code commit matches tested release.
- Pages job cannot execute from a PR/untrusted artifact; deploy permission is job-local; no paid services or uploaded runtime archives.
- GitHub links, 15 footer mappings, three-language public-account notice and the absence of project Cloudflare requests are checked on the affected integrated interface. Old private Worker tests are historical evidence, not launch requirements.
- Any enabled GoatCounter adapter passes fixed-request-field, credential-exclusion and aggregate-source checks; actual account/settings and integrated notice are recorded. No sample country/PV values or visitor-detail exports. Private vulnerability-reporting state is read back separately.
