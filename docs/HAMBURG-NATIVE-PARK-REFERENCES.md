# 原生公园轮廓仅作来源语境

`osm_park_footprint_reference` 接受 LLM 已明确复核的市内固定公园语境。选择文件列出
实际 OSM way ID；程序不搜索同名公园，不决定警方指的是哪一处场所。

每个选择必须保存当前 PBF 哈希、完整原始 way 标签、闭合节点编号和坐标、原始记录
哈希及几何哈希。轮廓可以重排闭合环的起点或方向，但不得删减、插值或移动节点。
无名原生面继续保持无名；一组面必须有一个一致的原生名称作为身份参考，不混合
不同具名公园。行政区、多边形替代点、缺少证明或市界外对象均不能进入该方法。

输出保留所有选定面和逐个原生来源，标记 `source_footprint_reference_only`、实际位置
未知和完整法律边界未知。不生成代表点，默认启用其他 footprint 的计数选项也不改变
这一限制。POI 的公园身份关联仅使用明确选定的原始面，不把内嵌游乐场或相邻公园
当作警方所指的同一公园；它仍是来源语境关联，不是场所涉案认定。

展示及所有来源、阶段、时间、角色、类别、关系与计数选择保持原样。

2,730 个市内 GIS 请求中，2,119 个有展示参考、611 个有明确缺口、0 个待处理；地图
另有 1,828 个未定位展示地点。这些不同口径不能互相替代。精确案件计数点仍为 0。
POI 为 109,326 个对象、78 类，1,846 条唯一公告–POI 语境关联。

公园名称对应由 LLM 比较警方地点叙述、地方议会同一议题的两个名称及三分区说明作
推断。议会全文来自独立 BV-HH 镜像，官方透明门户只核验会议及原记录入口；原站
连接超时，未声称已经直接抓到官方全文或两站字节相同。居民意见、犯罪感受和规划
讨论没有加入警方案情。三块 OSM 面也不证明历史法律边界或实际行动覆盖范围。
