# CrimeMaps GoatCounter country maps

The current provider is GoatCounter at `https://ryoushunnei.goatcounter.com/count`. Cloudflare collection, Turnstile and D1 remain retired. The account is private, with country collection enabled and sessions, individual pageviews, referrers, browser/system, screen size, region and language collection disabled. The account profile and source receipt are in ACCOUNT-SETTINGS.json. This is a setting snapshot, not a guarantee that future account changes have been reviewed.

The metric is **page views (PV)**, including ordinary reloads, excluding language changes and map operations. It is not unique people. Only `'/portal'` and `'/cities/<14 fixed lowercase IDs>'` are public scopes. The separate operator connection-test path is never included in a city export. Do not derive a path or title from URL query strings, selected police reports, search text, coordinates or language. `mountGoatCounter` accepts the fixed scope; `markAnalyticsLanguageNavigation` prevents a locale-triggered document reload from counting a second visit. Its one-use sessionStorage marker contains only the city and a timestamp and expires after 15 seconds; it is not a visitor/session identifier. If storage is unavailable, the real page load may count normally.

The official pinned count.v5.js is loaded only after explicit build activation on the approved HTTPS website. Its documented SRI is mandatory. Automatic on-load/click tracking is disabled before execution. Its exposed get_data hook is replaced with fixed path/title, blank referrer and the bot flag; query, screen size and selected content are removed. The official filter/url API prepares one POST with `mode:no-cors`, `credentials:omit` and `referrerPolicy:no-referrer`. No retries or polling can create duplicates. GPC/DNT, local production previews, frames, prerendering and the operator's official skip setting are respected. Country estimation necessarily processes the connection IP; with this account's sessions disabled the default eight-hour deduplication is not the counting rule. Do not promise that the provider never processes IP or that this project measures identifiable visitors. See [GoatCounter privacy](https://www.goatcounter.com/help/privacy), [sessions](https://www.goatcounter.com/help/sessions) and [script API](https://www.goatcounter.com/help/js).

## Activation and site integration

The candidate remains disabled unless `VITE_GOATCOUNTER_ENABLED=true` is set by the reviewed release process. The public count address does not need a secret. The read/export token must never be a VITE variable, JavaScript constant, README URL or public JSON value. Keep it in an ignored operator file or the central Berlin Actions secret `GOATCOUNTER_READ_TOKEN`. A city page mounts the existing component with its actual fixed city ID. The city portal calls `mountGoatCounter({city:'portal',enabled:...})` once at startup. Do not count map or feedback events. Only migration owns shared main/portal/config/CSP integration.

CSP requires `script-src` for the reviewed `https://gc.zgo.at/count.v5.js` and `connect-src https://ryoushunnei.goatcounter.com/count`. The static artifact gate must require its exact SRI and reject other accounts or whole-account/API permissions. No Goat image/frame permission is needed: the adapter uses one POST, and README SVGs are local aggregate snapshots. Preserve required map sources and restrictive default policy. [Official CSP](https://www.goatcounter.com/help/csp), [versioned SRI](https://www.goatcounter.com/help/countjs-versions).

## One account export, fourteen local snapshots

Use an existing manual/release/update operation to request one full-account JSON export, not fourteen exports. The API request is `POST /api/v0/export` with `{"format":"json"}`; it returns the export ID. Reuse that ID with GET `/api/v0/export/{id}` and `/api/v0/export/{id}/download`, following the provider's pending response, integrity hash and one-export-per-hour limit. The ZIP stays in an ignored local runtime directory; safely extract the allowlisted info/paths/locations/location_stats/hit_stats files there, without publishing the raw archive, created_by/operator metadata or account-wide records. No new scheduler is needed. [API](https://www.goatcounter.com/api.html), [JSON export schema](https://www.goatcounter.com/help/export-json).

After the operator's one download, reuse the same local directory for each city:

```sh
node src/goatcounter-snapshot.mjs berlin /absolute/ignored/json-export /absolute/city-repository
```

The CLI validates the account/export version, exact path-to-ID mapping, aggregate dates, nonnegative safe counts, dictionary references, non-overlapping daily/hourly rows and matching country/hit totals. It rebuilds totals from a complete snapshot instead of adding overlapping export days. Small country groups below 20 are hidden/combined; published values round down to 10. A city with no data, a corrupt/mismatched export or an older snapshot raises an error before replacing its last-good data. Treat no-city-data as retain-gray/retain-last-good, not as zero visitors. Do not invent city traffic to fill the first export.

Each successful city output has one aggregate JSON reproduced byte-for-byte in `web/public/safety/analytics/visitors-by-country.json` and `docs/assets/visitors-by-country.data.json`, six wide/mobile three-language SVGs and their source/time/hash sidecars. The website reads its own same-origin snapshot lazily once when expanded; switching language/reopening uses the cached data. Destroy aborts the request. Missing/failed/wrong-city/low-volume snapshots never create fake numbers. Website and README share this city aggregate. GitHub Camo caching means the README images are website statistics, not GitHub-reader IP/country tracking. [GitHub image proxy](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/about-anonymized-urls).

## Verification

`npm test` runs pure renderer/adapter tests. For the optional actual official-script compatibility checks, set GOATCOUNTER_SOURCE_FIXTURE to an ignored local count.v5.js whose hash matches the official SRI; without this source those marked checks are skipped and must not be reported as passed. No collector test sends real traffic. The local fixture page labels every number synthetic and rejects outbound requests. `test/preview/connection/index.html` is a separate operator-only, explicit one-click /_connection-test page; its disabled button proves an attempt, and the private API is required to prove reception. Do not publish the test preview or connection page.
