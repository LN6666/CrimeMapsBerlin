# Country and region geometry

The world card uses Natural Earth 1:50m admin-0 **map units**, pinned to repository commit `ca96624a56bd078437bca8184e78163e5039ad19`. [Source GeoJSON](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/ca96624a56bd078437bca8184e78163e5039ad19/geojson/ne_50m_admin_0_map_units.geojson), [map-unit explanation](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-details/), [public-domain terms](https://www.naturalearthdata.com/about/terms-of-use/). The source is 3,179,420 bytes, SHA-256 `b8d421aca6e9e08e8cdf09cc26af111cc3e0deba4fe915611d58ade71e8a4db0`. Raw download files are excluded from this patch; the static SVG paths, mapping and reproducible offline builder are included.

`scripts/analytics/build_world_boundaries.py SOURCE.geojson services/analytics/src/world-boundaries.mjs` checks that source SHA before conversion. It uses equirectangular coordinates, deterministic Ramer–Douglas–Peucker tolerance 0.12 degrees, native ring points for small islands, 0.01-degree quantization and relative integer SVG paths. No country positions, markers or centroids are invented. This is a compact cartographic illustration, not a survey or a police-location calculation. The resulting static module is about 146 kB / 61 kB gzip and is loaded by the web component only after the country disclosure is opened. There is no runtime geometry download, tile server or map engine.

`maps/country-mapping.json` records each source unit's original `ISO_A2` and chosen `ISO_A2_EH`. The latter supplies explicit connection-region mappings, including HK, TW, SG, GF and NO. A region can have several source units; they share one published count and are grouped into one SVG path. We do not merge HK/TW into CN or infer a parent code. XK follows the source and the region name supported by the runtime; this does not assert political recognition. Names are localized by `Intl.DisplayNames` and titles say countries **and regions**, not nationality or residence.

Somaliland, Northern Cyprus and Siachen Glacier have no source two-letter mapping and remain gray without parent assignment. Antarctica is omitted from the world outline; an AQ group remains in the ranking with a missing-outline note. Very small islands may be hard to see at card scale; their published figures remain readable in the ranking. A published code with no matching outline remains ranked and is never assigned to a nearby or parent polygon.

Only the exact public aggregate is passed to both map and ranking. Groups under 20 are already hidden or combined and values are rounded down to 10. `OTHER` has a gray ranking entry and no geographic shape. Suppressed, unknown or absent groups have null map values; gray means **no published group**, not zero visits. The palette uses only published values. No raw/exact hidden counts or IPs enter rendering, snapshots or source metadata. Natural Earth's cartographic boundary choices are retained; the visualization is not a statement about sovereignty.
